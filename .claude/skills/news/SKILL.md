# News

1. Use WebSearch for the topic with recent-date wording; open 2-4 distinct reputable sources with WebFetch (or the browser if a page needs rendering).
2. Summarize in 3-5 bullets: what happened, why it matters, with source names. Prefer primary reporting; note disagreement between sources.
3. State the date of each item. Never present old stories as current.
